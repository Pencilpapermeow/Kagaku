# Kagaku 科学

An offline-first study app for JEE Advanced 2027: formulas and tables to remember, practice in every JA question format, NTA-style CBT tests, and a Galti (mistake) Notebook. Built for one student; content lives in a separate private repo and arrives as packs.

- Live app: https://pencilpapermeow.github.io/Kagaku/ (after GitHub Pages is enabled)
- Start here: [`docs/HANDOVER.md`](docs/HANDOVER.md) → [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Content: [`docs/CONTENT_FORMAT.md`](docs/CONTENT_FORMAT.md), [`docs/WORKFLOW.md`](docs/WORKFLOW.md)
- Progress: [`docs/CHECKLIST.md`](docs/CHECKLIST.md)

```
npm ci
npm run dev          # local app
npm run check        # typecheck, unit tests, build, browser tests (phone + iPad)
```

No study material is stored in this repository.
